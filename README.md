## 📂 Contenuto del Repository

La repository è organizzata per corsi ed esercitazioni pratiche:

| Cartella | Corso / Categoria | Linguaggi & Tool | Descrizione |
| :--- | :--- | :---: | :--- |
| **[`📁 PROG1--C++`](./PROG1--C++)** | **Programmazione 1** | `C++` | Esercizi su puntatori, array, matrici, ricorsione, strutture dati base e gestione dei file. |
| **[`📁 esamiP1Pdf`](./esamiP1Pdf)** | **Esami Programmazione 1** | `C++` / `PDF` | Tracce d'esame passate, risoluzioni complete e refactoring di esercizi. |
| **[`📁 PROG2--JAVA`](./PROG2--JAVA)** | **Programmazione 2** | `Java` / `JavaFX` | Programmazione orientata agli oggetti (OOP), interfacce grafiche in JavaFX e pattern progettuali. |
| **[`📁 PROGFU--SML`](./PROGFU--SML)** | **Programmazione Funzionale** | `Standard ML` | Implementazioni di funzioni ricorsive, pattern matching, tipi algebrici e calcolo funzionale. |
| **[`📁 Algoritmi`](./Algoritmi/Laboratorio1)** | **Algoritmi e Strutture Dati** | `C++` | Laboratori pratici, risoluzione di problemi algoritmici con dataset di input/output. |
| **[`📁 Forza 4`](./Forza%204)** | **Mini-Games & Progetti Extra** | `C++` / `Python` | Implementazione del gioco del **Tris** in C++ e di **Forza 4** in Python. |
| **[`📁 siti`](./siti)** | **Web & Tools** | `HTML` `CSS` `JS` | Pagine web e utility interattive (es. *Geometry & Algebra Solver*). |
